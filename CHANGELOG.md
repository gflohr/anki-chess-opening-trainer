## Changelog

This project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

### 1.2.0 - 2026-11-02

* add possibility to add a tag to notes (GitHub PR #33)
* distinguish between initial position of standard chess and custom setup positions (GitHub issues [#37](https://github.com/gflohr/anki-chess-opening-trainer/issues/37))
* Fix "Open in Lichess" link. The link now points to the entire game, not just the resulting position.

### 1.1.0 - 2026-06-15

* add "Open in Lichess" link (GitHub issue [#28](https://github.com/gflohr/anki-chess-opening-trainer/issues/28) and PR [#29](https://github.com/gflohr/anki-chess-opening-trainer/pull/29))

### 1.0.3 - 2024-07-23

* fix GitHub issue [#23]((https://github.com/gflohr/anki-chess-opening-trainer/issues/23))) (ensure import dialog fits screen)

### 1.0.2 - 2024-07-05

* fix GitHub issue [#21]((https://github.com/gflohr/anki-chess-opening-trainer/issues/21))) which could make some combinations of colour and deck no
  longer selectable

### 1.0.1 - 2024-07-04

* fix a crash, when decks were deleted (GitHub issue [#15]((https://github.com/gflohr/anki-chess-opening-trainer/issues/15)))
* allow custom start position (GitHub issue [#16]((https://github.com/gflohr/anki-chess-opening-trainer/issues/16))))
* added Bulgarian translation

### 1.0.0 - 2024-06-12

* allow multiple imports per colour (thanks to Norbert Hies for the suggestion)
* validate the configuration on load against the JSON schema
